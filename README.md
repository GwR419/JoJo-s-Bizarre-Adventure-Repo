# JoJo-s-Bizarre-Adventure-Repo
This is a project where we will look at the end/final battle of JoJo's Bizarre Aventure part 5: Golden Wind manga that came out in 1999, and compare it to the animated series that came out in October of 2018. The goal of this project is to examine the differeces and similatities between the manga and the anime adaptation. By analyzing dialogue, pacing, and narrative structure, we hope to identify patterns in how the story changes between the two mediums with tools we use throughout DIGIT 210. As well as further building upon the website for more information and hopefully being more interactive.
