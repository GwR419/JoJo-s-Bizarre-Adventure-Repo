Our Sources

  • GitHub
    • This is our repository for our project. All of our code, project files, and website is in this repo.
  • JoJo Wiki
    • Used for inspiration for our website, as well as names for the "Characters" page. The images you see on the side of our website comes from this website.
  • Mangadex
    • This website contains all of the manga we needed for our project. We converted this to CBML.
  • CBML
    • Used to transform the manga into a comic format. This is the source of our code for our manga.
  • Anime Transcripts
    • This is where we gathered all of our jojoEpisodes for our anime portion. We used a web scraper to gather all of these files.
